# OCR 样张：韩文词间空格 / 竖排读序

## ko_words.png（1500×560，Malgun Gothic 72px）

| 行 | 文本 | 期望 OCR 输出 |
|---|---|---|
| 1 | 안녕하세요 세계 | `안녕하세요 세계`（词间一个空格） |
| 2 | 한국어 테스트 문장입니다 | `한국어 테스트 문장입니다` |
| 3 | 서울은 대한민국의 수도입니다 | `서울은 대한민국의 수도입니다` |
| 4 | JPEGView OCR 테스트 | `JPEGView OCR 테스트` |

当前实现会输出 `안녕하세요세계`：`NeedsSpaceBetween` 把 U+AC00–D7AF 当 CJK
（`OcrEngine.cpp:564`），前后都是韩文时不插空格。中文/日文这样是对的，韩文不对。

判定要看第 1–3 行：**词间是否保留空格**。第 4 行（韩文+拉丁）两版都应正常，
因为它两侧不都是 CJK。

## vertical_zh.png（980×720，SimSun 96px，三列五字）

```
夜 处 春      ← 阅读顺序：右列 → 中列 → 左列
来 处 眠
风 闻 不
雨 啼 觉
声 鸟 晓
```

期望读序：`春眠不觉晓` → `处处闻啼鸟` → `夜来风雨声`。
三列等高等长 → 每列的 `center()` 完全相同 → `MergeEngineLines` 的
`std::sort`（`OcrEngine.cpp:162`）退化为按 `left` 升序，即**左列先出**，
整体正好倒序。这个样张用来确认两件事：

1. WinRT 竖排返回的是"一列一行"还是"一行一行"（看行数与每行的文本）；
2. 倒序是否如预期发生（若行数=3 且首行是"夜来风雨声"，即证实）。
